# Customer_Behaviour_Analysis
Developed an end-to-end Customer Shopping Behaviour Analysis project using Python, PostgreSQL, SQL, and Power BI to uncover customer purchasing patterns and business insights.

# 📌 Project Overview

The **Customer Shopping Behaviour Analysis** project is an end-to-end data analytics solution that analyzes customer purchasing behavior, shopping trends, and sales performance. The project leverages Python for data preprocessing, PostgreSQL for data management, SQL for querying, and Power BI for interactive data visualization to generate actionable business insights.

---

# 🎯 Problem Statement

Retail businesses often struggle to understand customer purchasing patterns, product preferences, and revenue trends. This project aims to analyze customer shopping data to identify buying behavior, high-performing product categories, customer demographics, and seasonal trends, enabling data-driven business decisions.

---

# 🛠️ Tech Stack

* **Python** (Pandas, NumPy)
* **PostgreSQL**
* **SQL**
* **Power BI**
* **Microsoft Excel**
* **Jupyter Notebook**

---

# 📊 Results

* Analyzed customer purchasing behavior across multiple product categories.
* Identified top-performing categories and locations based on revenue.
* Evaluated customer spending patterns by gender, age, and subscription status.
* Built an interactive Power BI dashboard with KPIs and dynamic filters.
* Generated actionable insights to support business growth and strategic decision-making.

---

# 🚀 How to Run

1. Clone the repository.
2. Install the required Python libraries.
3. Load the dataset into PostgreSQL.
4. Execute the SQL queries for analysis.
5. Open the Power BI (.pbix) file and refresh the data source.
6. Explore the interactive dashboard using the available filters and slicers.
